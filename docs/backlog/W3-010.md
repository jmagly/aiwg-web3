# [W3-010] Extract validator lifecycle behind chain and custody adapters

## Objective

The Roko launch operator has useful lifecycle gates but embeds chain/host-specific enrollment and custody choices.

## Scope

Define an initial Substrate-oriented adapter contract for genesis verification, distinct node/session identity, backup/restore evidence, enrollment, atomic activation and reconciliation. Keep host topology and custody provider implementation outside generic roles.

## Acceptance criteria

- [ ] Existing-chain expansion never silently regenerates genesis
- [ ] Wrong genesis, duplicate identity and partial activation fixtures fail closed
- [ ] Secret values are absent from arguments, logs and receipts
- [ ] Custody interfaces are mockable without accessing production secrets
- [ ] Resume/recovery behavior is demonstrated in an isolated environment
- [ ] Scope is accurately labeled Substrate-oriented rather than universally chain-agnostic

## Dependencies and priority

Priority: P2. Depends on: W3-003, W3-005, W3-012.
