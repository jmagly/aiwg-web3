# [W3-004] Extract governance and account-abstraction skills

## Objective

Governance and sponsored execution are reusable but must not be mandatory or encode Roko economics.

## Scope

Separate proposal/delegation/quorum/timelock lifecycle from ERC-4337 user-operation, bundler, paymaster and session-policy handling. Bind supported entry-point/API versions through adapters.

## Acceptance criteria

- [ ] Governance mechanics are configured, with no assumed quadratic voting
- [ ] Tests cover quorum/timelock and unauthorized execution boundaries
- [ ] Tests cover expired/rejected sponsorship and unavailable bundler
- [ ] Paid fallback requires explicit user intent and exposes cost
- [ ] Skills remain usable independently of the full application role

## Dependencies and priority

Priority: P1. Depends on: W3-002, W3-003.
