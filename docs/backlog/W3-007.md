# [W3-007] Extract real-time 3D engineering as an independent optional addon

## Objective

The 3D specialization has broad reuse outside Web3, but contains project visuals and a broken LOD selector.

## Scope

Create an independent addon with graphics role, profiling skill and versioned examples. Keep orb/globe artwork in project examples, not the default contract. Define ownership/versioning without requiring Web3 installation.

## Acceptance criteria

- [ ] LOD boundary tests select correct detail at near/mid/far distances
- [ ] Missing WebGL, low-resource devices and reduced motion have verified fallbacks
- [ ] GPU, memory and frame budgets are project parameters
- [ ] No dependency on Roko branding or mandatory React wrapper
- [ ] Standalone addon install and a non-Web3 consumer evaluation pass

## Dependencies and priority

Priority: P1. Depends on: W3-003 for shared configuration conventions.
