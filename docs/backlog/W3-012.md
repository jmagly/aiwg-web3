# [W3-012] Select redistribution license and complete source-rights review

## Objective

The owner has not selected a license. Roko source definitions are audit inputs, not implicitly redistributable content.

## Scope

Obtain owner-selected SPDX license; classify each extracted file as original, rewritten or copied; establish permissions/notices for source prompts, code examples and assets. Keep private data and original branding out of distribution.

## Acceptance criteria

- [ ] Owner explicitly selects license and LICENSE file matches manifests
- [ ] Per-module source repository/commit/hash and transformation recorded
- [ ] Any copied material has verified permission and required notices
- [ ] Package scan excludes credentials, machine paths and private topology
- [ ] UNLICENSED/development-only status removed only after review
- [ ] Both mirrors carry identical licensing/provenance files

## Dependencies and priority

Priority: P0 release blocker. Depends on: None.
