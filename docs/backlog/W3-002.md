# [W3-002] Extract a version-aware EVM application integration specialist

## Objective

The existing Web3 specialist combines useful wallet/transaction orchestration with fixed Roko policy and incompatible example APIs.

## Scope

Implement the application-side role: chain/account state, RPC failover, ABI/address resolution, units, simulation, submission, receipts, replacements and finality. Route contract implementation to blockchain-developer. Read toolchain versions from the consuming lockfile.

## Acceptance criteria

- [ ] No embedded project names, contract addresses or assumed 18-decimal units
- [ ] Version-matched examples compile against a declared fixture lockfile
- [ ] Tests cover wrong chain, account change, rejection, revert, replacement and RPC failure
- [ ] Ambiguous submission is reconciled before retry
- [ ] Second-project evaluation and documented dependency contract
