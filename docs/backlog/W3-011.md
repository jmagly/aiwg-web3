# [W3-011] Automate deterministic packaging and consumer installation tests

## Objective

The scaffold packages locally, but distribution needs repeatable provider and Git-native verification beyond archive creation.

## Scope

Build CI around metadata validation, two reproducible archive builds, checksums, provider extraction, immutable-ref install/deploy/verify/remove and payload hash comparisons. Record supported AIWG/provider versions.

## Acceptance criteria

- [ ] Claude and Codex package twice with identical checksums
- [ ] Clean consumer installs from a reviewed Git commit on each host
- [ ] Declared agents/skills are present and resolvable after deployment
- [ ] Removal preserves unrelated consumer content
- [ ] Tampered payload, path escape, duplicate IDs and wrong manifest type are rejected
- [ ] Artifacts include version and provenance; no mutable dependency substitution

## Dependencies and priority

Priority: P0. Depends on: W3-003; W3-012 before public release.
