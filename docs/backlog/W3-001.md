# [W3-001] Deliver a distributable, opt-in Web3 framework

## Objective

Track the generalization of the audited Roko capabilities into a reusable AIWG lifecycle framework. The initial repository is a scaffold, not a completed specialist suite.

## Scope

Own scope → design → build → verify → release → operate gates. Coordinate W3-002 through W3-014. Keep AIWG core unmodified and maintain one canonical payload.

## Acceptance criteria

- [ ] Core EVM, security and QA modules are evaluated in a second project
- [ ] Optional modules and deferred work are explicitly documented
- [ ] Licensing, provenance, packaging and clean-consumer install gates pass
- [ ] Both remotes contain the same reviewed release commit
- [ ] Roadmap distinguishes delivered, deferred and unverified capabilities

## Dependencies and priority

Priority: P0. Depends on: None.
