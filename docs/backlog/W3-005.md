# [W3-005] Rewrite Web3 security review guidance and unsafe examples

## Objective

The audited security prompt teaches incorrect trust/validation examples and cannot be redistributed as-is.

## Scope

Replace hostname substring checks with parsed-origin policy; decode ABI selectors/arguments; replace SQL character stripping guidance; review CSP; remove invalid incident code and default blockchain logging of session metadata. Keep review distinct from incident execution.

## Acceptance criteria

- [ ] Regression fixtures reject deceptive hostnames and disguised approvals
- [ ] Versioned ABI decoding and allowance/permit review examples verified
- [ ] Application controls route to existing security-auditor; contract controls to relevant specialists
- [ ] Findings include severity, affected lines, reproduction and limits
- [ ] No claim of certification or complete protection from a checklist
- [ ] Independent second-project review has no unresolved high-severity prompt defects
