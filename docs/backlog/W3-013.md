# [W3-013] Establish signed releases, mirror policy and install documentation

## Objective

Dual Git remotes do not provide release provenance, publisher trust or automatic issue mirroring.

## Scope

Define canonical publisher identity, scoped signing custody and rotation/recovery process; immutable releases with archives/checksums, publisher envelope and supported install commands. Document Gitea engineering authority and GitHub community/mirror workflow.

## Acceptance criteria

- [ ] Same release commit/tag on both hosts verified
- [ ] Signed package verification fails on unknown publisher/tampering as expected
- [ ] Keys remain outside repository and CI logs
- [ ] Docs distinguish integrity-only installs from trusted signature verification
- [ ] Mirror recovery and issue-counterpart update process documented
- [ ] Release notes state exact supported modules and limitations

## Dependencies and priority

Priority: P1. Depends on: W3-011, W3-012, W3-014.
