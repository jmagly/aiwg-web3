# Web3 plan and act

Walk scope, design, build, verify, release, operate in order for a new project. Existing projects may enter a later phase with equivalent entry evidence. The coordinator identifies the entry phase and checks prerequisites.

For each phase use flows/<phase>.md and record templates/gate-evidence.md. Failed or unverified required gates prevent a readiness claim. Execution stays within the user's authorized scope. Corrective loops return to the owning phase with reproducible evidence.
