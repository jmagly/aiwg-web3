# Release phase

Entry: Verified candidate and authority.

Activities: review the entry evidence, select the applicable specialist,
produce the outputs and record gate results. NFT releases invoke
`nft-release-plan` and walk content, publication, deployment/mint,
reconciliation, and verification without combining their authority gates.

Outputs: Immutable package, license, checksums, install evidence, release
ledger, authority records, publication observations, transaction evidence, and
reconciliation report as applicable.

Exit gate: Distribution and any execution authorization gates satisfied.

Coordinator: `nft-release-steward` for NFT releases and
`web3-lifecycle-coordinator` otherwise. Use discovered existing specialists for
contract, security, deployment, and testing work.
