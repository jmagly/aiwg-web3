# AIWG Web3 workspace

Purpose: generalize reusable Roko Web3 capabilities into an opt-in AIWG framework.
Repository status: development scaffold, not a production release.

Gitea origin (roctinam/aiwg-web3) is the canonical engineering tracker and GitHub github (jmagly/aiwg-web3) is the distribution and community-facing mirror. Initial implementation issues are cross-filed on both at the owner's request; Gitea owns execution status. Update counterpart links when status changes; there is no automatic issue or Git mirroring configured.

The package source is .aiwg/plugins/web3-distribution/payload. Do not deploy AIWG into this repository to generate content copies. Use disposable consumers for deployment verification. Check aiwg artifacts path --json --check-write before writing AIWG payload.

No keys or credentials belong in this repository. Public distribution requires an owner-selected license and source provenance review. Work is additive; do not alter the original Roko agent definitions.
